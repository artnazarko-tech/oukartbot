# Сервер: шпаргалка

Сервер — Hetzner Cloud **CX23**, локация Falkenstein, Ubuntu 24.04.
IP, пароль и токены здесь **не записываем** (репозиторий публичный) — храни их у себя.

## Подключиться

```
ssh root@IP_СЕРВЕРА
```

Пароль при вводе не отображается — это нормально. Выйти с сервера — `exit`.
Все команды ниже выполняются **на сервере**, в папке бота:

```
cd /root/oukitel-bot
```

## Частые команды

| Что нужно | Команда |
|---|---|
| Работает ли всё? | `docker compose ps` (у всех статус `Up`) |
| Логи бота (живые) | `docker compose logs -f bot` (выйти — Ctrl+C) |
| Логи моста | `docker compose logs -f bridge` |
| Последние 50 строк логов | `docker compose logs --tail 50 bot` |
| Перезапустить бота | `docker compose restart bot` |
| Перезапустить всё | `docker compose restart` |
| Остановить всё | `docker compose down` |
| Запустить всё | `docker compose up -d` |
| Обновить вручную, не ждать 5 минут | `./update.sh` |
| История автообновлений | `cat update.log` |
| Какая версия сейчас | `git log --oneline -5` |
| Место на диске | `df -h /` |

## Где что лежит

```
/root/oukitel-bot/
├── bot.py, Dockerfile, ...        ← из GitHub, обновляются автоматически
├── .env                           ← ТОКЕН БОТА и настройки (только тут!)
├── data/store.json                ← пользователи, роли, станции, настройки сповіщень
├── data/history.db                ← история для статистики (SQLite; копить 400 дней)
├── data/schedules.json            ← старые расписания (v1), нужны только для миграции
├── update.log                     ← журнал автообновлений
└── oukitel-portable-bridge/
    └── config.json                ← ЛОГИН И ПАРОЛЬ Wonderfree (только тут!)
```

## Изменить настройки

```
nano .env                          # токен, ALLOWED_CHAT_IDS, пороги уведомлений
docker compose up -d               # применить
```

В nano: сохранить — **Ctrl+O**, потом Enter; выйти — **Ctrl+X**.

## Автообновление

Cron (планировщик Linux) раз в 5 минут запускает `update.sh`. Проверить, что он настроен:

```
crontab -l
```

Должна быть строка с `update.sh`. Если её нет — добавить:

```
(crontab -l 2>/dev/null; echo "*/5 * * * * /root/oukitel-bot/update.sh >> /root/oukitel-bot/update.log 2>&1") | crontab -
```

## Если что-то сломалось

1. `docker compose ps` — какая коробка не `Up`?
2. `docker compose logs --tail 50 ИМЯ` — что пишет в ошибке?
3. Скопируй ошибку и пришли Claude (**закрыв токены и пароли**).
4. Откатиться на прошлую версию, если последнее обновление сломало бота:
   ```
   git log --oneline -5             # найти номер рабочей версии, например 0ab5edb
   git reset --hard 0ab5edb
   docker compose up -d --build
   ```
   Внимание: через 5 минут cron снова поставит последнюю версию с GitHub —
   поэтому сразу скажи Claude, чтобы он исправил ошибку в репозитории.

за прошлый месяц. **Выключенный сервер тоже оплачивается** — остановить оплату можно
только удалением сервера.
