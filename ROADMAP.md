## 🚧 В работе: версия 2 (ветка `dev`)
Работаем в ветке `dev`, в `main` переносим по готовности каждого этапа (сервер обновляется только от `main`).

1. [ ] Устройства, пользователи, роли (админ / власник / гість — по каждому устройству), приглашения; миграция `schedules.json`
2. [ ] Меню: Стан / Керування / Сповіщення / Статистика; «Стан» и «Детальний стан»
3. [ ] Сповіщення по каждому пользователю и устройству (по умолчанию все выключены): свет появился/пропал (с длительностью),
       станция заряжена (без спама), заряд N% (порог настраивается), ошибка, нет данных 5 мин, вечерний итог (вкл/выкл + время)
4. [ ] Керування: AC / DC / USB вкл-выкл (по одному действию, следующее — после подтверждения от станции), лимит зарядки
5. [ ] Статистика: сегодня / неделя / месяц (вход, выход, отключения света, макс. мощность, среднее время зарядки), SQLite
6. [ ] Станции родных: отдельный мост на каждый аккаунт, логин/пароль вводятся только на сервере (не через Telegram)
7. [ ] Идеи: оценка автономности, подтверждение опасных действий, график заряда
